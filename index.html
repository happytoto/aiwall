How we use Claude

Claude가 분석의 중심에 있습니다

Claude is the core of our product, not an add-on. 긴 로그를 한 번에 읽는 능력과 정확한 추론이 보안 분석에 꼭 맞습니다.

  1. 수집

    고객 서버·장비의 로그를 에이전트로 수집합니다.

  2. 정제·마스킹

    개인정보와 비밀값을 지운 뒤 필요한 부분만 남깁니다.

  3. Claude 분석

    Claude API가 로그를 읽고, 도구를 호출해 IP 평판·취약점 정보를 확인한 뒤 판단합니다.

  4. 전문가 검수

    긴급 항목은 보안 전문가가 확인한 뒤 고객에게 보냅니다.

  5. 보고서·조치

    Claude가 보고서와 조치 가이드를 쓰고, 고객 피드백으로 계속 개선합니다.

Claude API (Messages) Tool use Structured output (JSON) Prompt caching Message Batches Long-context log analysis Human-in-the-loop review
